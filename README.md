# 游戏内AI与机器人系统

## 项目描述

游戏内AI与机器人系统的bug修复项目。核心模块 `ai/ai_bot_system.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 行为树只有射击一个节点无巡逻搜索撤退
- 感知系统只有视线检测无听觉无记忆无可疑度
- 决策系统只有射击一个决策无优先级
- bot通信完全没做bot之间不共享信息
- 难度系统是假的简单和困难属性完全一样
